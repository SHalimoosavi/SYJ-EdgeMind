# Models

This repository does not contain model weights. `.gguf` files are excluded via `.gitignore`.

Models are downloaded or imported separately (Phase 3 tooling). Users are responsible for complying with the applicable model license — each model retains its own upstream license, none of which are covered by this project's LICENSE.

`registry.json` in this directory is the configurable list of supported models and their verified metadata (parameter count, quantization, file size, estimated RAM requirement, recommended context, CPU requirements, license, source, limitations). It is currently empty — no models have been verified/registered yet (Phase 3). No entries will be added with invented URLs or unverified figures.
